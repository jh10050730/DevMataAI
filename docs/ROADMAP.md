## 2. AI 구조 — API 키 없이 Claude 사용

`.env`의 `AI_PROVIDER` 한 줄로 전환:

| 프로바이더 | 설명 | 필요한 것 |
|---|---|---|
| **claude-cli** (기본) | 이 PC의 Claude Code를 헤드리스로 호출. 구독 로그인 사용 | Claude Code 설치 + 로그인 |
| anthropic-api | Anthropic API 직접 호출 (배포용/빠른 응답) | `ANTHROPIC_API_KEY` |
| demo | 키가 아무것도 없을 때. 응답에 "데모" 표시 | 없음 |

**테스트 결과**
- 기본 옵션으로 호출: 1회 약 22만 토큰 (플러그인/MCP/스킬 프롬프트 포함) → 구독 한도 낭비
- 최소 모드(`--safe-mode --tools "" --strict-mcp-config --setting-sources "" --system-prompt ...`): **1회 약 680토큰, 1.5초**
- `--bare`는 구독 로그인을 못 써서 사용 불가

**제약**
- 서버가 이 PC에서 돌아갈 때만 작동 (클라우드 배포 불가)
- 구독 사용량을 Claude Code와 공유
- 개인용으로만 사용 (다른 사람에게 서비스하면 안 됨)

**나중에 추가 가능:** 앱 데이터를 MCP 서버로 열어서 Claude Code/Desktop에서 직접 질문하는 방식
